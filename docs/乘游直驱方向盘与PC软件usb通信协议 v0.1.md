# 2.获取设备信息

    设备信息数据在PC软件下发命令后设备会上报；另外设备信息数据有改变时，设备会主动上报数据

  pc软件下发命令

| Offset | Data | Description |
| --- | --- | --- |
| 0 | 0x81 | 获取命令 |
| 1-2 | 0x8101 | 设备信息命令，两字节 |
| 3 | 0x01-0x09 | 设备类型<br>        1： 基座<br>      2： 踏板<br>      3:   挂挡杆<br>      4：手刹<br>      5：序列档<br>      6：面盘<br>      其它：待定 |
