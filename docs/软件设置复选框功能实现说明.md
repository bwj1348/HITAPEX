# 软件设置复选框功能实现说明

## 概述

将设置页「软件设置」区域的三个单选项（RadioButton）改为复选项（CheckBox），并实现各自独立的功能：

| 选项 | 功能 |
|------|------|
| 开机自启动 | 勾选后，软件随 Windows 系统启动而自动运行 |
| 启动后最小化到托盘 | 勾选后，启动软件时自动隐藏到系统托盘 |
| 关闭软件后最小化到托盘 | 勾选后，点击右上角关闭按钮或按 Alt+F4 时隐藏到托盘而非退出 |

三个选项现在**相互独立**，可以任意组合勾选。

## 一、持久化配置层（Settings）

### 1.1 配置结构变更

**之前**：使用单个字符串 `StartupBehavior` 存储互斥状态（`"AutoStart"` / `"StartMinimized"` / `"CloseMinimized"` / `"None"`）。

**之后**：改为三个独立的布尔设置：

```xml
<Setting Name="AutoStart" Type="System.Boolean" Scope="User">
  <Value Profile="(Default)">False</Value>
</Setting>
<Setting Name="StartMinimizedToTray" Type="System.Boolean" Scope="User">
  <Value Profile="(Default)">False</Value>
</Setting>
<Setting Name="CloseMinimizedToTray" Type="System.Boolean" Scope="User">
  <Value Profile="(Default)">False</Value>
</Setting>
```

每个设置的 `Scope="User"` 表示值按用户独立存储，保存在 `%LOCALAPPDATA%\HITAPEX\` 下的 `user.config` 文件中。

### 1.2 C# 访问属性

`Settings.Designer.cs` 中生成对应的三个属性：

```csharp
public bool AutoStart { get; set; }
public bool StartMinimizedToTray { get; set; }
public bool CloseMinimizedToTray { get; set; }
```

业务代码通过 `Properties.Settings.Default.AutoStart` 等直接读写，调用 `.Save()` 持久化。

## 二、UI 层 —— 单选改复选

### 2.1 XAML 控件替换

```xml
<!-- 之前：RadioButton，同一 GroupName 保证互斥 -->
<RadioButton x:Name="AutoStartRadio"
             GroupName="SoftwareSettings"
             Checked="SoftwareSetting_Changed" ... />

<!-- 之后：CheckBox，各自独立的 Checked/Unchecked 事件 -->
<CheckBox x:Name="AutoStartCheckBox"
          Checked="AutoStartCheckBox_Changed"
          Unchecked="AutoStartCheckBox_Changed" ... />
```

### 2.2 CheckBox 自定义样式

在 `SettingsUserControl.xaml` 的资源字典中新增 `CheckBoxStyle`，与原有的 `RadioButtonStyle` 视觉风格一致：

- **外层**：红色描边矩形轮廓（RadioButton 是菱形，CheckBox 改为矩形以示区分）
- **内层**：勾选标记（checkmark path），`IsChecked=True` 时显示，红色描边
- **布局**：与 RadioButton 相同，Grid(22×18) + ContentPresenter 水平排列

### 2.3 事件处理

每个 CheckBox 绑定独立的 `Checked` 和 `Unchecked` 事件，不再共用一个互斥逻辑：

```csharp
// 开机自启动 — 勾选/取消时写入/删除注册表
private void AutoStartCheckBox_Changed(object sender, RoutedEventArgs e)
{
    if (AutoStartCheckBox.IsChecked == true)
    {
        SetAutoStartSetting(true);                    // 写注册表 Run 键
        Properties.Settings.Default.AutoStart = true;
    }
    else
    {
        SetAutoStartSetting(false);                   // 删注册表 Run 键
        Properties.Settings.Default.AutoStart = false;
    }
    Properties.Settings.Default.Save();
}

// 启动最小化到托盘 — 仅保存 bool 值
private void StartMinimizedCheckBox_Changed(object sender, RoutedEventArgs e)
{
    Properties.Settings.Default.StartMinimizedToTray =
        StartMinimizedCheckBox.IsChecked == true;
    Properties.Settings.Default.Save();
}

// 关闭最小化到托盘 — 仅保存 bool 值
private void CloseMinimizedCheckBox_Changed(object sender, RoutedEventArgs e)
{
    Properties.Settings.Default.CloseMinimizedToTray =
        CloseMinimizedCheckBox.IsChecked == true;
    Properties.Settings.Default.Save();
}
```

### 2.4 设置加载

`LoadSettings()` 方法从三个独立的 bool 设置恢复 CheckBox 状态：

```csharp
AutoStartCheckBox.IsChecked      = Properties.Settings.Default.AutoStart;
StartMinimizedCheckBox.IsChecked = Properties.Settings.Default.StartMinimizedToTray;
CloseMinimizedCheckBox.IsChecked = Properties.Settings.Default.CloseMinimizedToTray;
```

## 三、托盘图标底层实现（TrayIcon 类）

为了不引入 `System.Windows.Forms`（会与 WPF 命名空间大量冲突），使用 **Shell_NotifyIcon** Win32 API 的 P/Invoke 封装，纯 WPF 方案。

### 3.1 核心 API

```csharp
[DllImport("shell32.dll")]
private static extern bool Shell_NotifyIcon(int dwMessage, ref NOTIFYICONDATA lpData);
```

- `NIM_ADD` (0)：向托盘添加图标
- `NIM_DELETE` (2)：从托盘移除图标
- `NIM_MODIFY` (1)：修改图标属性

### 3.2 NOTIFYICONDATA 结构体

通过 `StructLayout` 与 Windows API 对齐，包含：
- `hWnd`：接收托盘消息的窗口句柄
- `uCallbackMessage`：自定义消息 ID（`WM_TRAYICON = 0x8001`）
- `hIcon`：图标句柄
- `szTip`：鼠标悬停提示文本

### 3.3 消息处理（WndProc）

通过 `HwndSource.AddHook` 挂载 WPF 窗口消息循环：

| 用户操作 | Windows 消息 | 响应 |
|---------|-------------|------|
| 双击托盘图标 | `WM_LBUTTONDBLCLK` | 触发 `DoubleClick` 事件 → 还原窗口 |
| 右键托盘图标 | `WM_RBUTTONUP` | 弹出 WPF ContextMenu |

### 3.4 右键菜单

使用 WPF 原生 `ContextMenu`（非 WinForms ContextMenuStrip）：

- **显示主窗口** → 触发 `DoubleClick` 事件
- **退出** → 触发 `ExitRequested` 事件 → 完整关闭程序

### 3.5 图标获取策略

```csharp
private static Icon GetDefaultIcon()
{
    // 优先从 exe 文件提取图标
    var icon = Icon.ExtractAssociatedIcon(Environment.ProcessPath);
    if (icon != null) return icon;
    // 降级使用系统默认程序图标
    return SystemIcons.Application;
}
```

## 四、MainWindow 托盘集成

### 4.1 初始化

构造函数末尾调用 `InitializeTrayIcon()`：

```csharp
private void InitializeTrayIcon()
{
    _trayIcon = new TrayIcon(this);          // 绑定当前窗口句柄
    _trayIcon.SetTooltip("HITAPEX");         // 托盘悬停提示
    _trayIcon.DoubleClick += RestoreFromTray; // 双击托盘 → 还原
    _trayIcon.ExitRequested += ExitApplication; // 右键菜单退出

    // 拦截窗口关闭事件
    Closing += (s, e) =>
    {
        if (Properties.Settings.Default.CloseMinimizedToTray)
        {
            e.Cancel = true;      // 取消关闭
            MinimizeToTray();     // 隐藏到托盘
        }
    };
}
```

### 4.2 最小化到托盘

```csharp
public void MinimizeToTray()
{
    Hide();                           // 隐藏窗口（任务栏也消失）
    if (_trayIcon != null)
        _trayIcon.Visible = true;     // 托盘图标出现
}
```

### 4.3 从托盘还原

```csharp
private void RestoreFromTray()
{
    Show();                           // 显示窗口
    WindowState = WindowState.Normal; // 确保不是最小化状态
    Activate();                       // 置前并获取焦点
    if (_trayIcon != null)
        _trayIcon.Visible = false;    // 隐藏托盘图标（可选）
}
```

### 4.4 关闭按钮行为

```csharp
private void CloseButton_Click(object sender, RoutedEventArgs e)
{
    if (Properties.Settings.Default.CloseMinimizedToTray)
        MinimizeToTray();              // 隐藏到托盘
    else
        Application.Current.Shutdown(); // 真正退出
}
```

### 4.5 资源清理

```csharp
protected override void OnClosed(EventArgs e)
{
    base.OnClosed(e);
    _trayIcon?.Dispose();  // 移除托盘图标、卸载消息钩子
}
```

## 五、启动流程控制

### 5.1 移除 StartupUri

`App.xaml` 中删除 `StartupUri="MainWindow.xaml"`，改为手动创建窗口：

```xml
<Application x:Class="HITAPEX.App" ... >
    <!-- 不再自动创建并显示 MainWindow -->
</Application>
```

### 5.2 重写 OnStartup

`App.xaml.cs` 中根据设置决定启动行为：

```csharp
protected override void OnStartup(StartupEventArgs e)
{
    base.OnStartup(e);

    var mainWindow = new MainWindow();

    if (HITAPEX.Properties.Settings.Default.StartMinimizedToTray)
        mainWindow.MinimizeToTray();  // 静默启动，仅显示托盘图标
    else
        mainWindow.Show();            // 正常显示窗口
}
```

这样在「启动最小化到托盘」选项勾选时，软件启动过程**不会闪现窗口**。

## 六、开机自启动实现

通过 Windows 注册表 `Run` 键实现：

```
路径：HKEY_CURRENT_USER\SOFTWARE\Microsoft\Windows\CurrentVersion\Run
键名：HITAPEX（程序集名称）
键值："C:\Path\To\HITAPEX.exe"
```

```csharp
private void SetAutoStartSetting(bool enable)
{
    using var key = Registry.CurrentUser.OpenSubKey(
        @"SOFTWARE\Microsoft\Windows\CurrentVersion\Run", true);

    var appName = Assembly.GetExecutingAssembly().GetName().Name;
    var appPath = Environment.ProcessPath;

    if (enable && appPath != null)
        key?.SetValue(appName, $"\"{appPath}\"");  // 写入注册表
    else
        key?.DeleteValue(appName, false);           // 删除注册表项
}
```

| 操作 | 注册表变化 |
|------|----------|
| 勾选自启动 | 在 `Run` 键下添加 `HITAPEX` 值 |
| 取消自启动 | 从 `Run` 键下删除 `HITAPEX` 值 |
