# game接口文档
## 概述

- **基础URL**: `http://localhost:1337/api` (开发环境) / `http://192.168.1.214:1337/api` (测试环境)
- **认证方式**: Bearer Token
- **数据格式**: JSON
- **版本**: 1.0

## 游戏API端点

### 获取游戏列表

- **URL**: `GET /api/games`
- **描述**: 获取支持的赛车游戏列表
- **方法**: GET

#### 查询参数

| 参数名 | 类型 | 必填 | 说明 | 示例值 |
|--------|------|------|------|--------|
| `populate` | string | 否 | 填充关联字段，使用 `*` 获取所有关联数据 | `*` |
| `pagination[pageSize]` | number | 否 | 每页返回的数据条数 | `100` |
| `pagination[page]` | number | 否 | 当前页码 | `1` |
| `pagination[withCount]` | boolean | 否 | 是否返回总数 | `true` |
| `sort[0]` | string | 否 | 排序字段，格式：`字段名:排序方向` | `name:asc` |
| `filters[$field][$operator]` | mixed | 否 | 字段过滤，支持多种操作符 | 见下方说明 |

**Strapi v5 常用操作符**:
- `$eq`: 等于
- `$ne`: 不等于
- `$lt`: 小于
- `$lte`: 小于等于
- `$gt`: 大于
- `$gte`: 大于等于
- `$contains`: 包含（字符串）
- `$in`: 在数组中

#### 获取全部数据的完整参数
```
GET /api/games?populate=*
```


**客户端调用示例**:
```javascript
// 使用fetch获取完整游戏数据
fetch('http://192.168.1.214:1337/api/games?populate=*', {
  method: 'GET',
  headers: {
    'Authorization': 'Bearer b04e4b2ffa76e8ca6fc718886f85ba14bc4f06fc2dc706c34f3b3d2a1ffa7e41d178fbb7d232c2a27249f0de3b4f005558a00dba5a7ecda453fb280f7019578f3790b1c872b7160efb6fdf985524c74aa217a56f31f81ad18cec31ceee82c3fee19cf51300229104d3842e300ab899646e229b5a9c3b6852effc7e80e2d4421d'
  }
})
```

#### 响应字段说明

| 字段名 | 类型 | 必返回 | 说明 | 数据结构 |
|--------|------|--------|------|----------|
| `id` | number | 是 | 游戏记录ID | 整数 |
| `documentId` | string | 是 | Strapi v5 文档标识符 | UUID字符串 |
| `name` | string | 是 | 游戏名称 | 文本类型 |
| `description` | string | 是 | 游戏描述 | 文本类型，可能为空 |
| `cover_image` | object | 否 | 游戏封面图片 | Media对象（见下方结构） |
| `bg_image` | object | 否 | 游戏背景图片 | Media对象（见下方结构） |
| `steam_id` | string | 否 | Steam游戏识别ID | 文本类型 |
| `createdAt` | string | 是 | 创建时间 | ISO 8601时间戳 |
| `updatedAt` | string | 是 | 更新时间 | ISO 8601时间戳 |
| `publishedAt` | string | 是 | 发布时间 | ISO 8601时间戳 |
| `locale` | string | 否 | 本地化语言代码 | 如: `"zh-CN"` |
