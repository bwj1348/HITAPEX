# 预设分享码 · 功能更新说明

> 2026-09-15 · 基于《用户系统api文档》v1.0 之后的增量变更。完整字段与端点细节见 [用户系统api文档.md](./用户系统api文档.md) 第八节，本文只讲**这次改了什么、客户端要做什么**。

## 一、功能概述

云预设新增**分享码**能力：每个云预设创建时自动生成全局唯一的 10 位分享码，其他用户（或游客）凭码导入，得到**导入时刻**预设内容的完整拷贝，落地为自己的**本地预设**。

核心语义（快照）：

- 导入 = 拷贝当下内容，服务端**不记录**任何导入行为
- 作者后续修改预设：已导入方不受影响；再次导入同一码将获得修改后的内容
- 作者删除预设：分享码随之失效，导入返回 `SHARE_CODE_NOT_FOUND`；已导入方的本地副本不受影响

## 二、新增端点：凭分享码导入预设

```
POST /api/user-presets/import
```

**公开接口，无需登录**（未登录游客同样可导入）。请求体：

```json
{
  "code": "b3n8p5rwky"
}
```

- `code`：分享码，**大小写不敏感**，首尾空白自动忽略

**成功响应**：

```json
{
  "success": true,
  "data": {
    "config_data": { "force": 90, "angle": 360 },
    "owner": { "username": "极速车神" }
  },
  "message": "请求成功"
}
```

| 字段 | 说明 |
|------|------|
| `data.config_data` | 导入时刻的预设内容，结构由客户端自行约定 |
| `data.owner.username` | 作者用户名，用于展示"来自 xxx"（可能为 null，建议兜底） |

**客户端职责**：拿到响应后**立即**用 `config_data` 在本地创建一份本地预设——快照落地完全在客户端完成，服务端不存副本。

**错误**：

| code | 触发条件 |
|------|---------|
| `SHARE_CODE_NOT_FOUND` (404) | 码缺失 / 格式错误 / 不存在 / 预设已删除（统一返回，不区分原因） |
| `SYSTEM_RATE_LIMITED` (429) | 全局限流（IP 60/min） |

## 三、响应字段变更（加性，向后兼容）

所有预设接口（列表 / 单查 / 创建 / 更新 / 删除）的响应实体**新增 `share_code` 字段**：

```json
{
  "id": 2,
  "documentId": "oc8ax8bwr154l3xlepgk8i2j",
  "config_data": { "force": 90, "angle": 360 },
  "createdAt": "2026-08-10T12:00:00.000Z",
  "updatedAt": "2026-08-10T12:00:00.000Z",
  "publishedAt": "2026-08-10T12:00:00.000Z",
  "share_code": "B3N8P5RWKY"
}
```

- `share_code`：10 位大写字母数字（字符集已去掉易混淆的 0/O/1/I），创建时服务端生成，**不可指定、不可修改**，随预设删除一起失效
- 现有逻辑不处理该字段也不受影响；做分享功能时直接从创建/列表响应里取用即可

## 四、文档勘误（重要，请核对）

v1.0 文档的预设响应示例与实际返回有出入，现已修正。**实际行为从未变过**，本次只是把文档改对：

1. 预设响应里**从来没有 `user` 字段**（旧示例多写了）——若客户端反序列化是严格模式（多余/缺失字段报错）请检查；宽松模式无需处理
2. 预设响应里一直有 **`publishedAt`** 字段（旧示例漏写了）——v5 固定返回，与草稿发布无关，可忽略

## 五、客户端接入清单

- [ ] 分享入口：预设详情/列表取 `share_code` 展示 + 复制（建议按 5-5 分组显示，如 `B3N8P-5RWKY`，仅展示用，导入时不带横杠）
- [ ] 导入入口：输入码 → 调 `POST /api/user-presets/import`（未登录也可用）→ 用返回的 `config_data` 创建本地预设，作者名可标注"来自 {owner.username}"
- [ ] 导入失败处理：`SHARE_CODE_NOT_FOUND` 提示"分享码无效"；`SYSTEM_RATE_LIMITED` 提示稍后再试
- [ ] 快照提示（可选）：告知用户导入的是当前版本，作者后续修改不会同步
