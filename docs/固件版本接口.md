# 固件版本接口

## 认证
与游戏接口认证一致

## api端点
- **URL**: `GET /api/firmware-versions`
- **描述**: 获取固件版本及更新文件

## 获取全部数据的完整参数
GET /api/firmware-versions?populate=*

##  响应字段说明
| 字段名 | 类型 | 必返回 | 说明 | 数据结构 |
|--------|------|--------|------|----------|
| `id` | number | 是 | 海报记录ID | 整数 |
| `documentId` | string | 是 | Strapi v5 文档标识符 | UUID字符串 |
| `pid` | string | 是 | 供应商识别码 | 文本类型 |
| `vid` | string | 是 | 产品标识符 | 文本类型 |
| `version` | string | 是 | 版本号 | 文本类型 |
| `device_name` | string | 是 | 设备名 | 文本类型 |
| `update_log` | string | 是 | 更新日志 |  Markdown格式文本，需客户端使用markdown渲染器显示 |
| `update_file` | object | 是 | 固件更新文件 | Media对象（见下方结构） |
| `createdAt` | string | 是 | 创建时间 | ISO 8601时间戳 |
| `updatedAt` | string | 是 | 更新时间 | ISO 8601时间戳 |
| `publishedAt` | string | 是 | 发布时间 | ISO 8601时间戳 |
| `locale` | string | 否 | 本地化语言代码 | 如: `"zh-CN"` |
