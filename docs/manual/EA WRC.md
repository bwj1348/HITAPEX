# EA WRC - 遥测接入与排坑指南

## 连接方式

EA WRC 通过 UDP 输出遥测数据，需要**手动修改配置文件**才能开启：

1. 启动一次游戏后退出（生成配置文件夹）
2. 打开 `Documents\My Games\WRC\telemetry\config.json`
3. 将 `bEnabled` 设为 `true`，配置目标 IP（`127.0.0.1`） 和端口（如 `26666`）
4. 保存后重新启动游戏，插件监听对应端口即可接收数据

> 速度单位原始为 **m/s**，插件内部已转换为 km/h。

## 已知限制

EA WRC 为拉力赛，大量归一化参数不适用：

| 参数 | 状态 |
|------|------|
| TC 触发状态 | 不支持（无直接字段，滑移率推断结果不可靠） |
| TC / ABS 档位 | 不支持 |
| 最大转速 (maxRpm) | 不支持 |
| 燃油系统 | 不支持 |
| ERS 系统 | 不支持 |
| DRS | 不支持 |
| 维修区限速器 | 不支持 |
| 旗语 (raceFlag) | 不支持 |
| 轮胎滑移角 / 总滑移 | 不支持 |

### ABS 触发状态可用

EA WRC 提供 `vehicle_cluster_abs`（仪表盘 ABS 指示灯）字段，可直接获取 ABS 是否介入，是少数支持辅助系统触发状态的拉力赛游戏。

## 测试推荐

| 测试目标 | 推荐场景 | 验证要点 |
|----------|---------|---------|
| 基础数据（速度/挡位/踏板） | 任意赛段 | 观察速度、转速、档位、踏板变化 |
| ABS 触发 | 任意车辆 | 重刹观察 isAbsActive 状态 |
