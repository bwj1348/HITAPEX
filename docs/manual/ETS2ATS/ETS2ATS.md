# 欧卡/美卡 (ETS2 / ATS) - 遥测接入与排坑指南

## 连接方式

欧卡/美卡需要**手动安装第三方共享内存插件**才能输出遥测数据，游戏本身不自带遥测功能。

1. 将共享内存插件 DLL 文件（项目使用 `cwxyAETS2Telemetry.dll`）放入游戏安装目录下的 `bin\win_x64\plugins\` 文件夹（若无 `plugins` 目录需手动创建）
2. 启动游戏即可自动生效，无需游戏内额外设置
3. 插件通过共享内存读取数据，共享内存名称为 `Local\cwyxSCSTelemetry`（可通过配置自定义）

> SCS 官方仅提供了一套遥测 SDK，具体实现由社区插件完成，不同插件的共享内存名称和结构可能不同。本项目基于上述 DLL 进行适配。

> 速度单位原始为 **m/s**，插件内部已转换为 km/h。

## 已知限制

卡车模拟器不支持大部分赛车类参数：

| 参数 | 状态 |
|------|------|
| TC / ABS | 不支持（卡车无牵引力/防抱死控制系统） |
| ERS 系统 | 不支持 |
| DRS | 不支持 |
| 轮胎滑移数据 | 不支持 |
| 旗语 (raceFlag) | 不支持（非赛道场景） |
| TC / ABS 档位 | 不支持 |

### isPitLimiterActive 实际为驻车制动

归一化参数中的 `isPitLimiterActive` 在卡车模拟器中映射的是**驻车制动（手刹）状态**，而非维修区限速器。

### 鼠标捕获问题（欧卡2）

欧卡2存在抢夺鼠标焦点的问题，可能导致遥测客户端操作异常。如遇到此问题，需进入游戏 **设置 → 无障碍 → 重置鼠标控制器**。

## 测试推荐

卡车模拟器偏日常驾驶，参数容易触发，默认驾驶即可验证所有支持参数，无特殊场景要求。
