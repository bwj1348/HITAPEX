# AC Evo (Assetto Corsa Evo) - 遥测接入与排坑指南

## 连接方式

AC Evo 启动后自动开启遥测，无需任何游戏内设置。全部数据通过共享内存读取。

> 速度单位直接为 **km/h**。

## 已知限制

无。所有支持参数均正常获取，接入过程中未发现异常。

## 测试推荐

| 测试目标 | 推荐车辆 | 场景 |
|----------|---------|------|
| 基础数据（速度/挡位/踏板） | 任意 GT 车辆 | 任意练习赛 |
| TC / ABS 触发 | 高扭矩 GT3 车辆（如 Lamborghini Huracan） | 出弯地板油验证 TC，重刹验证 ABS |
| ERS 充放电 | 混合动力车型（engineType = HYBRID） | 出弯观察放电，重刹观察充电，切换 ERS 部署/回收模式观察档位变化 |
| DRS | GT3 车辆或方程式赛车 | 练习赛中按键开关，观察 DRS 0/1 跳变 |
| TC/ABS 档位调节 | 任意车辆 | 练习赛中调整 TC/ABS 级别，观察档位数值变化 |
