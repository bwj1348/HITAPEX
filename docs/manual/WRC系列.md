# WRC 系列 (WRC 8/9/10) - 遥测接入指南

## 连接方式

WRC 8/9/10 通过**共享内存**输出遥测数据，需要**安装第三方补丁 DLL** 才能启用遥测功能。

补丁原理：替换游戏目录中的一个 DLL（`PhysXCooking64_s.dll`），注入共享内存遥测协议。共享内存名称为 `Local\WRC-8wSotWzFKAhBlbW10ZJBKaWMdWszbBXg`。

> **WRC Generations** 原生支持 UDP 遥测，无需安装补丁。详见 [WRC Generations](./WRC%20Generations.md)。

## 安装步骤（WRC 8/9/10）

### 方式一：自动安装

1. 关闭游戏
2. 将补丁包解压到 WRC 安装目录
3. 运行 `InstallWrc10.bat`

### 方式二：手动安装

1. 关闭游戏
2. 将补丁包解压到 WRC 安装目录
3. 将 `PhysXCooking64_s.dll` 重命名为 `PhysXCooking64_s_org.dll`
4. 将 `WrcInjectionPayload.dll` 重命名为 `PhysXCooking64_s.dll`
5. 启动游戏即可

> **注意**: `PhysXCooking64_s_org.dll` 必须存在，且应为游戏最新版本的原始文件。

## 已知限制

| 参数 | 状态 |
|------|------|
| TC / ABS 触发状态 | 不支持 |
| TC / ABS 档位 | 不支持 |
| 燃油系统 | 不支持 |
| ERS 系统 | 不支持 |
| DRS | 不支持 |
| 维修区限速器 | 不支持 |
| 旗语 (raceFlag) | 不支持（拉力赛无赛道旗语） |
| 轮胎滑移数据 | 不支持（待统一标准化） |
| 发动机状态 | 不支持 |
| WRC 10 开场赛段 | 无遥测数据 |

## 游戏更新注意事项

当 Steam 或 Epic 更新游戏时，补丁 DLL 会被覆盖还原，导致遥测失效。解决方法：重新运行 `InstallWrc10.bat` 即可。

补丁对游戏小版本更新具有兼容性，但若游戏发生重大改动，补丁可能永久失效。

## 测试推荐

| 测试目标 | 推荐场景 | 验证要点 |
|----------|---------|---------|
| 基础数据（速度/挡位/踏板） | 任意拉力赛段 | 观察速度、转速、档位、踏板变化 |
| 悬挂数据 | 高起伏路面 | 观察悬挂行程变化 |
| 补丁安装成功 | 启动游戏进入赛段 | SDK 返回有效数据（speed > 0 或 rpm > 0） |
