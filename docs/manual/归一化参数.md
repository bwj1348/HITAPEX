# 归一化参数定义

本文档记录 NormalizedData 结构体中所有归一化参数的定义，包括类型、取值范围和含义。

## 初始参数（初始版本已存在）

### 基础驾驶参数
```cpp
float speed;       // 速度，单位：km/h
float rpm;         // 引擎当前转速
int gear;          // 挡位：0为空挡(N)，1-8为前进挡，-1为倒挡(R)
float throttle;    // 油门踏板开度：0.0 - 1.0
float brake;       // 刹车踏板开度：0.0 - 1.0
float steer;       // 转向角度：-1.0(左) 到 1.0(右)
```

## 第一批添加参数

### 发动机参数
```cpp
float maxRpm;      // 最大发动机转速 (RPM)
```

### 状态标志
```cpp
bool isPitLimiterActive;  // 维修区限速器是否激活
bool isTcActive;          // 牵引力控制系统是否激活
bool isAbsActive;         // 防抱死制动系统是否激活
bool isDrsAvailable;      // 可调尾翼是否可用
bool isDrsActive;         // 可调尾翼是否激活
```

### 轮胎滑移数据
数组大小定为4，顺序约定：0=FL(左前), 1=FR(右前), 2=RL(左后), 3=RR(右后)

```cpp
float slipRatio[4];      // 纵向滑移率 (-1.0 to +inf)
float slipAngle[4];      // 滑移角 (弧度，带正负号)
float combinedSlip[4];   // 总滑移 (正交合成值)
```

## 第二批添加参数

### ERS/混合动力系统
不支持时填充默认值。

```cpp
float ersCharge;            // ERS电量百分比 0.0-1.0（无ERS系统=-1.0）
int ersDeployMode;          // ERS部署档位索引（-1=不支持, 0+=实际档位索引，含义因车型ers.ini而异）
bool isErsActive;           // ERS是否正在工作（false=未工作/不支持）
int ersRecoveryLevel;       // ERS回收级别（-1=不支持, 0-100百分比）
```

### 发动机状态系统
不支持时填充默认值。

```cpp
bool isEngineRunning;      // 发动机是否正在运行（false=未运行/不支持）
bool isIgnitionOn;         // 点火开关是否开启（false=未点火/不支持）
int enginePowerMode;       // 发动机动力档位（-1=不支持, 0+=实际档位索引）
```

### 牵引力控制/ABS档位系统
此处tc/abs指档位索引（离散级别），非物理数据中的float强度值。不支持时填充默认值。

```cpp
int tcLevel;        // TC牵引力控制档位（-1=不支持, 0=关闭, 1+=实际档位级别）
int absLevel;       // ABS防抱死制动档位（-1=不支持, 0=关闭, 1+=实际档位级别）
int tcCutLevel;     // TC削减档位（-1=不支持, 0=关闭, 1+=实际削减级别）
```

### 燃油系统
不支持时填充默认值。注意AC/ACC/F125原始数据单位为kg，需转换（汽油密度约0.75 kg/L）。

```cpp
float fuelRemaining;      // 剩余燃油量（升），-1.0=不支持
float fuelRemainingPct;   // 剩余燃油百分比 0.0-1.0，-1.0=不支持
```

### 赛事旗语系统
不支持时填充默认值。

```cpp
int raceFlag;     // 当前旗帜状态（FlagType枚举值）
```

#### 旗语枚举定义
```cpp
enum FlagType {
    FLAG_NONE       = 0,   // 无旗/绿旗（正常比赛）
    FLAG_BLUE       = 1,   // 蓝旗（让车）
    FLAG_YELLOW     = 2,   // 黄旗（危险/减速）
    FLAG_BLACK      = 3,   // 黑旗（取消资格）
    FLAG_WHITE      = 4,   // 白旗（慢车）
    FLAG_CHECKERED  = 5,   // 方格旗（比赛结束）
    FLAG_PENALTY    = 6,   // 处罚旗
    FLAG_ORANGE     = 7,   // 橙旗（机械故障）
    FLAG_RED        = 8,   // 红旗（比赛暂停）
    FLAG_SC         = 9,   // 安全车
    FLAG_VSC        = 10,  // 虚拟安全车
};
```
