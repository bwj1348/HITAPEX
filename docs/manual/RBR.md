# Richard Burns Rally (RBR) - 遥测接入与排坑指南

## 关于本作

Richard Burns Rally 是一款经典拉力赛模拟游戏，以其真实的物理引擎和严苛的赛道设计著称，至今仍有活跃的社区维护和模组支持。

## 连接方式

RBR 通过 UDP 输出遥测数据，遥测开关位于**进入游戏前的主界面**中直接选择开启，无需修改配置文件。插件监听对应端口即可接收数据。

> 速度单位直接为 **km/h**，无需转换。

## 已知限制

作为一款经典拉力赛游戏，RBR 的遥测数据仅包含基础驾驶参数（速度、转速、挡位、踏板、转向），大量归一化参数不支持，具体请参照参数覆盖总览表。

## 测试推荐

RBR 支持参数少，默认驾驶即可验证所有支持参数，无特殊场景要求。
