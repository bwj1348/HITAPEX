# DiRT 系列 (DiRT Rally 2.0) - 遥测接入与排坑指南

## 连接方式

DiRT 系列通过 UDP 输出遥测数据，需要**手动修改配置文件**才能开启：

1. 启动一次游戏后退出（生成配置文件）
2. 打开 `Documents\My Games\DiRT Rally 2.0\hardwaresettings\hardware_settings_config.xml`
3. 修改以下 UDP 参数：

```xml
<udp enabled="true" extradata="3" ip="127.0.0.1" port="20777"/>
```

4. 保存文件并**设为只读**（防止游戏启动时覆盖）
5. 插件监听 20777 端口即可接收数据

> 速度单位原始为 **m/s**，插件内部已转换为 km/h。

## 已知限制

DiRT 系列为拉力赛，大量归一化参数不适用：

| 参数 | 状态 |
|------|------|
| TC / ABS 触发状态 | 不支持（协议中相关字段实际不可用） |
| TC / ABS 档位 | 不支持 |
| 燃油系统 | 不支持（DiRT 系列无燃油消耗机制，协议中燃油字段实际不起效） |
| ERS 系统 | 不支持 |
| DRS | 不支持 |
| 维修区限速器 | 不支持 |
| 旗语 (raceFlag) | 不支持（拉力赛无赛道旗语） |
| 轮胎滑移数据 | 不支持（原计划通过轮速与车速差值计算滑移率，但实测数据异常，已标记不支持） |

## 测试推荐

| 测试目标 | 推荐场景 | 验证要点 |
|----------|---------|---------|
| 基础数据（速度/挡位/踏板） | 任意拉力赛段 | 观察速度、转速、档位、踏板变化 |
| 悬挂/轮速 | 高起伏路面 | 观察悬挂行程和四轮轮速变化 |
