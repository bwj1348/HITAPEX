# F1 系列 (F1 22/23/24/25) - 遥测接入与排坑指南

## 连接方式

通过 UDP 广播接收遥测数据。需在游戏设置中开启 UDP 遥测输出。

> F1 24/25 速度单位直接为 **km/h**。F1 22/23 速度单位为 m/s，插件内部已转换为 km/h。

## 已知限制

### TC/ABS 仅有档位设置，无触发状态

F1 系列的 `tcLevel` 和 `absLevel` 反映的是**游戏系统选项中的辅助设置**（如 TC 关/中/高，ABS 关/开），而非车辆自身的 TC/ABS 档位。协议不提供 TC/ABS 是否正在介入的动态状态，`isTcActive` 和 `isAbsActive` 始终为 false。

### ERS 回收级别不支持

F1 的 ERS 回收由引擎自动管理，不支持手动调节。`ersRecoveryLevel` 始终为 -1。

### 轮胎滑移数据因版本而异

| 版本 | slipRatio | slipAngle | combinedSlip |
|------|-----------|-----------|-------------|
| F1 22 | - | - | OK（近似值） |
| F1 23 | - | - | - |
| F1 24 | OK | OK | OK |
| F1 25 | OK | OK | OK |

### 旗语限制

F1 系列旗语仅支持绿旗、蓝旗、黄旗。不提供红旗、黑旗、白旗、方格旗等（安全车/虚拟安全车状态通过 Session 包单独获取）。

## 测试推荐

| 测试目标 | 推荐场景 | 验证要点 |
|----------|---------|---------|
| 基础数据（速度/挡位/踏板） | 任意练习赛 | 观察速度、转速、档位变化 |
| ERS 充放电 | 任意比赛模式 | 出弯观察放电，重刹观察充电，切换 ERS 部署模式 |
| DRS | 排位赛或正赛 | DRS 检测区域按键观察跳变 |
| TC/ABS 档位 | 设置菜单 | 调整 TC/ABS 辅助级别，观察档位数值变化 |
| 轮胎滑移 | F1 24 或 F1 25 | 练习赛中观察滑移数据（F1 22/23 无或仅有近似值） |
| 安全车 | Quick Race（加入 AI） | 等待安全车出动，观察 VSC/SC 状态 |
