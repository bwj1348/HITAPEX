# AMS2 / PC2 / PC3 - 遥测接入与排坑指南

## 连接方式

AMS2、Project CARS 2 和 Project CARS 3 均通过共享内存 `$pcars2$` 输出遥测数据，只需将游戏内遥测设置的共享内存切换为Project Car 2即可。

> 三个游戏共用一个适配器，但共享内存版本和参数支持差异较大：
> - **AMS2**: 共享内存版本 v13，参数支持最完整
> - **PC2**: 共享内存版本 v9，缺少多项扩展字段
> - **PC3**: 基于 v9，在 PC2 基础上进一步削减

> 速度单位原始为 **m/s**，插件内部已转换为 km/h。

## 已知限制

### AMS2

AMS2 参数支持最完整，无特殊限制。

> 发动机点火状态（isIgnitionOn）无独立字段，通过发动机运行状态同步判断。

### PC2

PC2 共享内存版本较低，与 AMS2 相比缺少许多扩展字段：

| 参数 | 状态 |
|------|------|
| TC 触发状态 (isTcActive) | 不支持 |
| TC / ABS 档位 | 不支持 |
| 维修区限速器 (isPitLimiterActive) | 不支持（PC2 的 SPEED_LIMITER 标志位实际表示"是否在维修区"，而非限速器状态） |
| DRS | 不支持 |
| ERS 系统 | 不支持（PC2 的 Boost 系统与 AMS2 的 ERS 行为不同，未映射） |

#### 旗语触发困难

PC2 旗语系统存在但游戏中极难触发，常规比赛几乎无法自然产生旗语。实测需通过反向触发黑旗等方式才能获取旗语数据。

### PC3

PC3 在 PC2 的基础上进一步简化，除 PC2 所有不支持的参数外，额外受以下限制：

| 参数 | 状态 |
|------|------|
| 燃油系统 | 不支持（无燃油消耗，数据为静态值：固定 1 升 / 100%） |
| 轮胎损耗 | 不支持 |
| ERS 系统 | 不支持 |

#### 旗语几乎无法触发

PC3 游戏内几乎无法触发任何旗语，raceFlag 标注为**部分支持**。

## 测试推荐

### AMS2

| 测试目标 | 推荐场景 | 验证要点 |
|----------|---------|---------|
| 基础数据 | 任意练习赛 | 速度、转速、挡位、踏板 |
| TC / ABS 触发 | 配备辅助系统的车辆 | 出弯地板油观察 isTcActive，重刹观察 isAbsActive |
| DRS | 开放座舱赛车 | 按键开关 DRS，观察 isDrsAvailable / isDrsActive |
| ERS | 混合动力车型 | 出弯观察放电，重刹观察充电，切换 ersDeployMode |

### PC2

| 测试目标 | 推荐场景 | 验证要点 |
|----------|---------|---------|
| 基础数据 | 任意练习赛 | 速度、转速、挡位、踏板 |
| ABS 触发 | 任意车辆 | 重刹观察 isAbsActive |
| ERS | 配备 Boost 的车辆 | 观察 Boost 充放电 |
| 旗语 | 自定义比赛 | 需通过特殊方式触发，比如开局反方向开触发黑旗 |

### PC3

PC3 支持参数少，默认驾驶即可验证所有支持参数。
